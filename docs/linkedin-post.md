## Main Post (recommended)

Excited to share something we've been building — **GridStorm**, an open-source, TypeScript-native platform for enterprise data applications.

One platform. One license. One API pattern.
Data grids. PDF toolkit. AI-powered document intelligence.

**Why we built it**
Most teams end up gluing together 4–5 different libraries for grids, exports, PDF viewing, and document AI — each with its own API, theming model, and learning curve. GridStorm brings it all under one coherent architecture so you ship features instead of plumbing.

**What's inside (39 packages, MIT-licensed)**
→ Virtual scrolling — 100K+ rows at 60fps
→ 19+ composable plugins — sort, filter, group, pivot, aggregation, editing, clipboard, Excel/PDF export, sparklines, charts, master-detail, tree data, SSRM
→ Multi-framework — first-class React 18, Vue 3, Svelte 5 adapters (headless core works anywhere)
→ < 50 KB tree-shakeable core — pay only for what you import
→ CSS theming — light, dark, and high-contrast, runtime-switchable
→ Full PDF toolkit — viewer, text extraction, search, annotations, redaction
→ AI & intelligence — PII detection, smart form fill, document classification, MCP server for Claude/LLM integration
→ i18n + RTL support out of the box
→ 1,084+ tests across 52 test files, TypeScript 5.9 strict mode

**The community is picking it up**
We published on npm about a week ago, and the early traction already means a lot:

Thank you to every early adopter — we see you, and it genuinely motivates the team.

## Alternate 2 — Story / Founder tone

A year ago we kept running into the same problem on enterprise projects: stitching together a data grid, a PDF viewer, an export engine, and some form of document AI — four different libraries, four different APIs, four different theming systems, and a lot of glue code.

So we built **GridStorm** — one open-source platform with all of it under a single architecture.

What you get in one MIT-licensed monorepo:
• A headless TypeScript grid engine with a plugin system (19+ plugins — sort, filter, group, pivot, edit, export, charts, SSRM, tree data, master-detail)
• Virtual scrolling that holds 60fps on 100K+ rows
• React 18, Vue 3, and Svelte 5 adapters — same core, same API
• A full PDF toolkit: viewer, text search, annotations, redaction
• AI plugins: PII detection, smart form fill, document classification, and an MCP server so Claude/LLMs can drive the document workflow
• Light, dark, and high-contrast themes via CSS variables
• i18n and RTL support
• < 50 KB tree-shakeable core, 1,084+ tests, TypeScript 5.9 strict mode

We published to npm about a week ago, and the early numbers already mean a lot:
• @gridstorm/i18n — 136 weekly downloads
• @gridstorm/theme-default — 130 weekly downloads
• @gridstorm/plugin-pagination — 127 weekly downloads

To everyone who installed, starred, or shared — thank you. This is just the start.
