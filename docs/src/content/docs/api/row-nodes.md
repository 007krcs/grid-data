---
title: Row Nodes
description: Complete reference for the RowNode interface, covering data rows, group rows, pinned rows, and all row-level properties.
---

Every row in a GridStorm grid is represented by a `RowNode` object. Row nodes wrap your data objects with metadata needed for rendering, selection, grouping, and virtual scrolling.

## Interface

```ts title="RowNode<TData>"
interface RowNode<TData = any> {
  // Identity
  id: string;
  data: TData | undefined;
  sourceIndex: number;
  displayIndex: number;

  // Nesting
  level: number;

  // Display geometry
  rowHeight: number;
  rowTop: number;

  // Tree / Group
  parent: RowNode<TData> | null;
  children: RowNode<TData>[] | null;
  expanded: boolean;
  group: boolean;
  groupField: string | null;
  groupValue: any;
  leafChildrenCount: number;

  // Aggregation
  aggData: Record<string, any> | null;

  // Selection
  selected: boolean;
  selectable: boolean;

  // Detail (master-detail)
  detail: boolean;

  // Pinning
  rowPinned: 'top' | 'bottom' | null;

  // Dirty tracking
  version: number;
}
```

## Property Reference

### Identity

| Property | Type | Description |
|---|---|---|
| `id` | `string` | Unique row identifier. Generated by `getRowId()` or defaults to array index. |
| `data` | `TData \| undefined` | Reference to your data object. `undefined` for group/filler rows. |
| `sourceIndex` | `number` | Index in the original (unfiltered, unsorted) data array. `-1` for group rows. |
| `displayIndex` | `number` | Index in the displayed (post-filter/sort/group) list. Updated after reprocessing. |

### Nesting Level

| Property | Type | Description |
|---|---|---|
| `level` | `number` | Nesting depth for grouped data. `0` for top-level rows. Each group level increments by 1. |

### Display Geometry

| Property | Type | Description |
|---|---|---|
| `rowHeight` | `number` | Row height in pixels. Set from `GridConfig.rowHeight`. |
| `rowTop` | `number` | Vertical offset from the top of the virtual scroll container. Used for absolute positioning. |

### Tree / Group Properties

| Property | Type | Description |
|---|---|---|
| `parent` | `RowNode \| null` | Parent group node. `null` for top-level rows. |
| `children` | `RowNode[] \| null` | Child rows (for group nodes). `null` for leaf rows. |
| `expanded` | `boolean` | Whether this group row is expanded. Only meaningful when `group` is `true`. |
| `group` | `boolean` | `true` if this is a group row, `false` for data (leaf) rows. |
| `groupField` | `string \| null` | The column ID this group is keyed on. `null` for non-group rows. |
| `groupValue` | `any` | The value of the group key (e.g., `'Engineering'` for a department group). |
| `leafChildrenCount` | `number` | Total number of leaf (data) descendants, recursively. |

### Aggregation

| Property | Type | Description |
|---|---|---|
| `aggData` | `Record<string, any> \| null` | Aggregated values for group rows. Keyed by column ID. `null` for non-group rows or when no aggregation is configured. |

Example:
```ts
// For a group row with sum(salary) and avg(age):
node.aggData = {
  salary: 250000,
  age: 32.5,
}
```

### Selection

| Property | Type | Description |
|---|---|---|
| `selected` | `boolean` | Whether this row is currently selected. |
| `selectable` | `boolean` | Whether this row can be selected. Defaults to `true`. |

### Detail

| Property | Type | Description |
|---|---|---|
| `detail` | `boolean` | Whether this is a detail row in a master-detail setup. |

### Pinning

| Property | Type | Description |
|---|---|---|
| `rowPinned` | `'top' \| 'bottom' \| null` | Whether this row is pinned to the top or bottom of the grid. `null` for normal rows. |

### Dirty Tracking

| Property | Type | Description |
|---|---|---|
| `version` | `number` | Incremented when row properties change. The renderer uses this for targeted re-renders, skipping rows whose version has not changed. |

## Row Types

### Data Rows

Standard rows that hold your data objects:

```ts
node.group === false
node.data !== undefined
node.children === null
```

### Group Rows

Created by the Grouping plugin to represent grouped categories:

```ts
node.group === true
node.data === undefined
node.children !== null
node.groupField === 'department'
node.groupValue === 'Engineering'
node.leafChildrenCount === 15
```

### Pinned Rows

Created from `pinnedTopRowData` or `pinnedBottomRowData`:

```ts
node.rowPinned === 'top' // or 'bottom'
```

Pinned rows are excluded from sorting, filtering, and pagination.

## Accessing Row Nodes

### By ID

```ts
const node = api.getRowNode('emp-123');
```

### By Display Index

```ts
const firstVisibleRow = api.getDisplayedRowAtIndex(0);
const lastVisibleRow = api.getDisplayedRowAtIndex(api.getDisplayedRowCount() - 1);
```

### Iteration

```ts
api.forEachNode((node, index) => {
  if (node.selected) {
    console.log('Selected:', node.id, node.data?.name);
  }
});
```

### From Events

Many events include the affected row node:

```ts
api.addEventListener('cell:clicked', (event) => {
  const node = event.node;
  console.log('Clicked row:', node.id, 'value:', event.value);
});

api.addEventListener('row:groupOpened', (event) => {
  console.log('Group', event.node.groupValue, 'expanded:', event.expanded);
});
```

## Mutating Row Nodes

Row nodes use a hybrid immutability approach. Some properties are designed to be mutated directly:

### Mutable Properties

- `selected` -- Updated by the Selection plugin
- `expanded` -- Updated by the Grouping plugin
- `rowTop` -- Updated during row processing
- `displayIndex` -- Updated during row processing
- `aggData` -- Updated by the Aggregation plugin
- `version` -- Increment after mutations to trigger re-renders

### Updating Data

To update a cell value directly:

```ts title="Direct data update"
const node = api.getRowNode('emp-123');
if (node?.data) {
  node.data.salary = 75000;
  node.version++;
  api.refreshCells({ rowIds: ['emp-123'], colIds: ['salary'] });
}
```

:::caution
Direct mutation bypasses the command bus and event system. For tracked, auditable changes, use the editing system instead.
:::

## GridState Row Collections

The grid state contains two row-related collections:

| Collection | Type | Description |
|---|---|---|
| `rowNodes` | `Map<string, RowNode>` | All row nodes, keyed by ID. Includes data rows, group rows, and pinned rows. |
| `displayedRowIds` | `string[]` | Ordered array of row IDs currently visible (after filter, sort, group, pagination). |

Access via the API:

```ts
const state = api.getState();
const totalNodes = state.rowNodes.size;
const displayedCount = state.displayedRowIds.length;
```
