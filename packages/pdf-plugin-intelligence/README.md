# @gridstorm/pdf-plugin-intelligence

PDF document classification, data extraction, and summarization.

## Install

```bash
npm install @gridstorm/pdf-plugin-intelligence
```

## Usage

```typescript
import { IntelligencePlugin } from '@gridstorm/pdf-plugin-intelligence';

const pdf = createPDFEngine({ plugins: [IntelligencePlugin()] });
```

## Features

- **Document classification**
- **Key-value extraction**
- **Text summarization**
- **Pattern recognition**
