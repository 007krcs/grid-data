# @gridstorm/pdf-renderer

Canvas-based PDF renderer with DOM text layer and annotation support.

## Install

```bash
npm install @gridstorm/pdf-renderer
```

## Usage

```typescript
import { PDFRenderer } from '@gridstorm/pdf-renderer';

const renderer = new PDFRenderer({ container: element });
renderer.render(page);
```

## Features

- **Canvas rendering**
- **DOM text layer for selection**
- **Annotation layer**
- **Zoom and pan controls**
