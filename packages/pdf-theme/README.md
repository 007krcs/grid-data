# @gridstorm/pdf-theme

CSS custom properties theme for the GridStorm PDF viewer.

## Install

```bash
npm install @gridstorm/pdf-theme
```

## Usage

```typescript
import '@gridstorm/pdf-theme/dist/index.css';
```

## Features

- **CSS custom properties**
- **Light and dark modes**
- **Customizable via CSS variables**
