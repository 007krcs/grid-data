# @gridstorm/plugin-row-reorder

Drag-and-drop row reordering.

## Install

```bash
npm install @gridstorm/plugin-row-reorder
```

## Usage

```typescript
import { RowReorderPlugin } from '@gridstorm/plugin-row-reorder';

const grid = createGridEngine({ plugins: [RowReorderPlugin()] });
```

## Features

- **Drag-and-drop reordering**
- **Visual drag indicators**
- **Index and ID-based move commands**
