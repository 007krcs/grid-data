# @gridstorm/plugin-sparklines

Inline SVG sparkline renderers for grid cells.

## Install

```bash
npm install @gridstorm/plugin-sparklines
```

## Usage

```typescript
import { SparklinesPlugin } from '@gridstorm/plugin-sparklines';

const grid = createGridEngine({ plugins: [SparklinesPlugin()] });
```

## Features

- **Line, bar, area, win-loss sparklines**
- **Inline cell rendering**
- **Customizable colors**
- **Pure SVG**
